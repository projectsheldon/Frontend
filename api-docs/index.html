Reseller API

Programmatically manage your licenses with our REST API.

Authentication

All API requests require your API key to be passed in the Authorization header:

Authorization: Bearer YOUR_API_KEY

Generate your API key in the Reseller Dashboard under Settings.

Base URL

# Production https://api.projectsheldon.com/reseller # Local Development http://localhost:3350/reseller

GET /myavailable

Returns all available licenses that are not yet resold.

Example Request

curl -X GET "https://api.projectsheldon.com/reseller/myavailable" \ -H "Authorization: Bearer YOUR_API_KEY"

Response

{ "ok": true, "licenses": [ { "key": "ps-XXXX-XXXXXXX-XXX", "product": "lifetime", "expiration": "2027-01-01T00:00:00.000Z", "created_at": "2026-01-01T00:00:00.000Z" } ] }

POST /licenseinfo

Get information about a specific license.

Request Body

Parameter Type Description
license string The license key

Example Request

curl -X POST "https://api.projectsheldon.com/reseller/licenseinfo" \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"license": "ps-XXXX-XXXXXXX-XXX"}'

Response

{ "ok": true, "info": { "key": "ps-XXXX-XXXXXXX-XXX", "product": "lifetime", "expiration": "2027-01-01T00:00:00.000Z", "is_expired": false, "is_assigned": false, "created_at": "2026-01-01T00:00:00.000Z" } }

GET /fetchlicense

Get a random available license from your stock.

Example Request

curl -X GET "https://api.projectsheldon.com/reseller/fetchlicense" \ -H "Authorization: Bearer YOUR_API_KEY"

Response

{ "ok": true, "license": { "key": "ps-XXXX-XXXXXXX-XXX", "expiration": "2027-01-01T00:00:00.000Z" } }

POST /assignlicense

Assign a license to a Discord user. A claim token will be generated and sent to the user via DM.

Request Body

Parameter Type Description
license string The license key to assign
discord_user_id string The Discord user ID to assign to

Example Request

curl -X POST "https://api.projectsheldon.com/reseller/assignlicense" \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"license": "ps-XXXX-XXXXXXX-XXX", "discord_user_id": "123456789012345678"}'

Response

{ "ok": true, "message": "License assigned successfully" }

Rate Limiting

API requests are limited to 100 requests per minute per API key. If you exceed this limit, you'll receive:

{ "ok": false, "message": "Rate limit exceeded. Try again later." }

Error Responses

All errors follow this format:

{ "ok": false, "message": "Error description here" }
Status Code Meaning
401 Invalid or missing API key
400 Invalid request parameters
403 Access denied (not a verified reseller)
429 Rate limit exceeded
