Overview

Lua 5.4 + sol2

The Sheldon Lua VM provides a full Lua 5.4 scripting environment powered by sol2. Scripts can interact with the Roblox game instance, render overlays, manipulate memory, and more.

PropertyDetail
LanguageLua 5.4
Bindingsol2 (C++ to Lua)
Loaded std libsbase, math, table, string
Compound assignmentsx += 1, x -= 1, etc. (preprocessed to vanilla Lua)

Basic Usage

print("Hello from Sheldon!")
local player = game:FindFirstChildOfClass("Players").LocalPlayer
print("Current player:", player.DisplayName)

Drawing ESP

cheat.Register("onPaint", function()
  local players = game:FindFirstChildOfClass("Players")
  for _, player in ipairs(players:GetChildren()) do
    local char = player.Character
    if char then
      local root = char:FindFirstChild("HumanoidRootPart")
      if root then
        local screenPos, onScreen = utility.WorldToScreen(root.Position)
        if onScreen then
          draw.TextOutlined(player.Name, screenPos.x, screenPos.y, Color3.Red())
        end
      end
    end
  end
end)

Custom UI Tab

gui.AddTab("My Script", function()
  if imgui.Begin("My Window") then
    imgui.Text("Hello from Lua!")
  end
  imgui.End()
end)
